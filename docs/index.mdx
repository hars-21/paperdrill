PaperDrill is a simulated spot-trading platform backed by a live matching engine and order book. You can trade in the web interface, automate orders through the REST API, and consume live market data over WebSocket.

<Warning>
	PaperDrill uses simulated balances. No real funds, deposits, withdrawals, or financial returns are
	involved.
</Warning>

## Choose a path

- To make your first authenticated request, follow the [Quickstart](/quickstart).
- To build an integration, read [Authentication](/authentication), [API overview](/api-reference/overview), and the generated API reference.
- To consume live data, start with [WebSocket streams](/websocket) and [Order book](/orderbook).
- To trade manually, open the [PaperDrill platform](https://paperdrill.dev/markets).

## Endpoints

| Interface        | URL                                      |
| ---------------- | ---------------------------------------- |
| REST API         | `https://api.paperdrill.dev/v1`          |
| WebSocket        | `wss://api.paperdrill.dev`               |
| Trading platform | [paperdrill.dev](https://paperdrill.dev) |

Public market-data endpoints do not require authentication. Order and account reads require an API key with the appropriate scope. Creating or cancelling an order also requires a verified PaperDrill account.

## Core conventions

- Use symbols in underscore form, such as `SOL_USD`.
- Send prices and quantities as decimal strings, not JSON numbers.
- Read each market's precision before constructing an order.
- Treat every order response as authoritative because an order can fill immediately.
- Reconnect and resubscribe after a WebSocket interruption.

See [API overview](/api-reference/overview) for precision, timestamp, pagination, and retry conventions.
