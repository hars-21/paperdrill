PaperDrill is a simulated spot-trading platform backed by a live matching engine and order book. You can trade through the web interface, connect a bot through the API, and compare portfolio performance on the leaderboard.

<Warning>
	PaperDrill uses simulated balances. No real funds, deposits, withdrawals, or financial returns are
	involved.
</Warning>

## API endpoints

| Interface        | URL                                      |
| ---------------- | ---------------------------------------- |
| REST API         | `https://api.paperdrill.dev/v1`          |
| WebSocket        | `wss://api.paperdrill.dev`               |
| Trading platform | [paperdrill.dev](https://paperdrill.dev) |

Public market-data endpoints do not require authentication. Trading and account endpoints require a verified PaperDrill account and an API key with the appropriate scope.

## Where to begin

- If you want to trade through code, follow the [quickstart](/quickstart).
- If you need market data, start with [markets and candles](/markets) or the [WebSocket streams](/websocket).
- If you are integrating the full API, review the [endpoint reference](/api-reference) and [error format](/errors).
