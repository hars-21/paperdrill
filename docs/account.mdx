---
title: "Track balances and portfolio"
description: "Read available funds, locked balances, portfolio performance, and private fills."
---

Account endpoints use API-key authentication. Balances and portfolio values are decimal strings so clients do not lose precision.

## Understand balances

`GET /balances` requires `ACCOUNT_READ`. Add `?asset=USD` when you need only one asset.

```bash
curl https://api.paperdrill.dev/v1/balances \
  --header "x-api-key: $PAPERDRILL_API_KEY"
```

```json
{
	"USD": { "available": "9748.50", "locked": "251.50" },
	"SOL": { "available": "2.00", "locked": "0.00" }
}
```

- `available` can be used for a new order.
- `locked` is reserved by open orders.
- Cancelling an order releases its unfilled reservation.
- Fills move value between assets and can change both fields.

Always refresh balances after order activity instead of calculating the authoritative balance only on the client.

## Review balance history

`GET /balances/history` returns every recorded balance movement newest first. Each entry includes the resulting `available`, `locked`, and `total` balances plus the signed `deltaAvailable`, `deltaLocked`, and `deltaTotal` that produced them.

```bash
curl "https://api.paperdrill.dev/v1/balances/history?asset=USD&reason=fill.settled&page=1&limit=20" \
  --header "x-api-key: $PAPERDRILL_API_KEY"
```

| Parameter | Meaning                                                                                                              |
| --------- | -------------------------------------------------------------------------------------------------------------------- |
| `asset`   | Optional asset filter.                                                                                               |
| `reason`  | Optional reason filter: `initialized`, `deposited`, `credited`, `order.locked`, `order.released`, or `fill.settled`. |
| `page`    | Page number, starting at 1.                                                                                          |
| `limit`   | Entries per page, up to 100.                                                                                         |

The response also returns `assets`, a per-asset summary, and `filtered`, which reports the filtered entry count and net change for the selected asset.

## Chart balance history

`GET /balances/history/series` returns a chart-ready trajectory. Pass `asset` for a single asset or omit it to value the whole account at current market prices. Supported ranges are `24h`, `7d`, `30d`, `90d`, and `all`; the default is `30d`.

```bash
curl "https://api.paperdrill.dev/v1/balances/history/series?range=30d" \
  --header "x-api-key: $PAPERDRILL_API_KEY"
```

When the total series includes a funded asset without a usable mark price, `partial` is `true` and the series excludes that asset from its valuation.

## Track portfolio performance

`GET /portfolio` requires `ACCOUNT_READ`. It values positions in the platform quote asset and compares current equity with the account's PnL baseline.

```bash
curl https://api.paperdrill.dev/v1/portfolio \
  --header "x-api-key: $PAPERDRILL_API_KEY"
```

| Field                | Meaning                                          |
| -------------------- | ------------------------------------------------ |
| `equity`             | Current portfolio value                          |
| `baselineEquity`     | Value used as the PnL starting point             |
| `pnl` / `pnlPercent` | Change from the baseline                         |
| `baselineAt`         | Time at which the baseline was recorded          |
| `asOf`               | Oldest market-price timestamp used for valuation |
| `partial`            | `true` when a position could not be fully priced |
| `positions`          | Per-asset balances, mark price, and value        |

Treat `partial: true` as an incomplete valuation. Do not present it as the value of the entire portfolio without a warning.

## Reconcile with private trades

Use `GET /trades` with the `ORDER_READ` scope to retrieve your fills newest first. Each record identifies your side, maker status, and related order.

```bash
curl "https://api.paperdrill.dev/v1/trades?limit=100" \
  --header "x-api-key: $PAPERDRILL_API_KEY"
```

Use order history for intent and status, private trades for executions, and balances for the current authoritative funds.
